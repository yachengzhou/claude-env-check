Claude / ChatGPT 防封号环境检测常见问题

本工具面向使用 Claude、ChatGPT 与科学上网的用户，一键检查节点 IP、系统时区、浏览器语言、字体与渲染指纹是否与出口地区自洽，并排查 WebRTC、DNS、IPv6 泄漏，降低因环境矛盾被风控标记的概率。所有检测在浏览器本地完成。

账号被封或提示地区不可用，是环境问题吗？

平台会综合出口 IP 类型、时区与语言一致性、支付方式、手机号和使用行为判断。环境检测只能排除浏览器与系统层面的矛盾，不能保证账号结果；提示“region”多为 IP 地区问题，提示“disabled after review”才是账号层面的处置。

已经挂了美国节点，还需要改什么？

建议让系统时区、浏览器首选语言、区域格式与节点所在地保持一致，并确认 UDP 流量没有绕过代理。仅改浏览器语言而系统时区仍是 Asia/Shanghai，是最常见的矛盾组合。

机房 IP 和住宅 IP 有什么区别？

机房 IP 在多数风控库里会被标记为 hosting / proxy，住宅 IP 更接近普通宽带用户。本工具会显示出口 ASN、反向解析与 hosting / proxy 标记，方便你判断当前节点质量。

WebRTC、DNS、IPv6 泄漏是什么？怎么排查？

系统代理模式下 TCP 走代理但 UDP 可能直连，WebRTC 会暴露真实公网 IP；DNS 与 IPv6 也可能从本地网络出口发出。建议使用 TUN 模式接管全局流量，再用本工具逐项验证出口是否一致。

检测数据会上传吗？

不会。所有计算都在本机浏览器内完成，IP 归属地通过公共接口查询，不收集、不上传浏览器指纹或其他数据。

检测结果仅在本机浏览器内计算，不会上传任何数据；IP 归属地通过公共接口查询。
本工具用于环境自检与隐私排查，环境打分不构成任何平台行为的保证。
